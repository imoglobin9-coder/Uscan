# Security policy

If you find a vulnerability, please **do not open a public issue**. Use GitHub's
[private vulnerability reporting](../../security/advisories/new) on this repository instead.
Include steps to reproduce and the version/commit you tested. You'll get a reply as soon as possible.

uscan processes untrusted files (PDFs and images). See "Sign-in and security" in the README for the built-in
protections and the known limits (no encryption at rest; PDFs are parsed in-process).
